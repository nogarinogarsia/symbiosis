# 냥냥 유전 하우스 — 명세서 & 구현 현황

실제 고양이 털색·무늬 유전 원리를 모사한 교배 + 3D 툰 고양이 돌봄·수집 게임 (웹 프로토타입).
이 문서는 기획 협의 내용과 인계 명세서를 정리한 것이며, 각 항목 옆에 구현 상태를 표시합니다.

- ✅ 구현됨
- ⏳ **아직 구현되지 않음**
- 🔸 부분 구현 (한계를 옆에 적음)

플레이: https://nogarinogarsia.github.io/symbiosis/ (PC 브라우저, 인터넷 연결 필요)
기획 요약 문서: [GAME_OVERVIEW.md](GAME_OVERVIEW.md)

## 실행

빌드 도구 없이 동작합니다(Node 불필요). Three.js는 CDN(jsdelivr)에서 불러옵니다.

```bash
python serve.py 8765
```

- 게임: http://localhost:8765/index.html (진행은 브라우저 localStorage에 저장, 우상단 `새 게임`으로 초기화)
- 유전 엔진 검증: http://localhost:8765/tests.html
- 렌더 갤러리: http://localhost:8765/viewer.html
- 조작: WASD/방향키 또는 클릭으로 이동. 내 우리의 고양이를 클릭하면 돌보기 창, 동물샵·교배집·이웃 NPC에 다가가면 해당 창이 열립니다.
- 우상단 `+1시간` `+1일` 은 개발용 시간 건너뛰기(성격 형성·쿨다운 확인용)

## 2. 유전 시스템 (명세서 §2~3)

설명 범주 3개: ① 멘델/복대립 ② 성염색체 연관(Barr body는 하위 메커니즘) ③ 다유전자

| 좌위 | 내용 | 상태 |
|---|---|---|
| B (B>b>bl) | 블랙/초콜릿/시나몬 | ✅ |
| D | 희석 (블루/라일락/폰/크림) | ✅ |
| A | 아구티 (오렌지는 A와 무관하게 태비 표시) | ✅ |
| T (M/m) | 고등어/클래식 (게임용 단순화) | 🔸 실제 태비 구조는 더 복잡 |
| S | ss / Ss / SS = 없음 / 바이컬러 / 하이화이트 (3단계 단순화) | 🔸 실제 흰반점 연속 변이 미반영 |
| C (TYR) | C, cb, cs / 포인트·세피아·밍크 | 🔸 일부 대립유전자만, 마스크 기반 표현 (포인트·세피아·밍크 색 보정) |
| L | 장모 (솜털 셸 표현) | ✅ |
| I | 실버/스모크 | 🔸 밝은 색조로만 표현 (점박이 표현은 요청으로 제거) |
| O (X연관) | 오렌지/크림/토티·삼색 | ✅ 암컷 O/o만 토티, 수컷 토티(XXY) ⏳ **아직 구현되지 않음** |
| P1~P3 | 가상 다유전자 → 농도 5단계 | ✅ |

| 항목 | 상태 |
|---|---|
| genotype → phenotype → visualVariant → catalogId → rarity 분리 | ✅ |
| seed 기반 재현성 (`RNG`, mulberry32) | ✅ |
| Barr body: 유전자형과 패치 마스크 분리, 패치는 개체 seed로 생성·비유전 | ✅ |
| 토티 확률 = 2p(1−p) | ✅ 실측 37% (p=0.25) |
| 도감 수를 패치 seed로 부풀리지 않음 | ✅ |
| 일반 외형 1,000종 이상 | ✅ 표현형 11,040종 / 렌더 구별 10,326종 (4비트 양자화 기준) |

| 레거시 8종(B/D/S 3좌위) 마이그레이션 규칙 | ⏳ **아직 구현되지 않음** (시작 고양이는 12좌위로 새로 생성하기로 결정해 대체) |
| 외형 파라미터(수염·귀·얼굴·체형) 부모 기반 유전 + 약간 변이 | ✅ |
