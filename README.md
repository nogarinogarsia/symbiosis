# 냥냥 유전 하우스 — 명세서 & 구현 현황

실제 고양이 털색·무늬 유전 원리를 모사한 교배 + 3D 툰 고양이 돌봄·수집 게임 (웹 프로토타입).
이 문서는 기획 협의 내용과 인계 명세서를 정리한 것이며, 각 항목 옆에 구현 상태를 표시합니다.

- ✅ 구현됨
- ⏳ **아직 구현되지 않음**
- 🔸 부분 구현 (한계를 옆에 적음)

플레이: https://nogarinogarsia.github.io/symbiosis/ (PC 브라우저, 인터넷 연결 필요)
기획 요약 문서: [GAME_OVERVIEW.md](GAME_OVERVIEW.md)

## 실행

빌드 도구 없이 동작합니다(Node 불필요). Three.js는 CDN(jsdelivr)에서 불러옵니다.

```bash
python serve.py 8765
```

- 게임: http://localhost:8765/index.html (진행은 브라우저 localStorage에 저장, 우상단 `새 게임`으로 초기화)
- 유전 엔진 검증: http://localhost:8765/tests.html
- 외형·동작 갤러리: http://localhost:8765/viewer.html (개체 선택·네 발 보행/휴식 동작 미리보기·드래그 회전)
- 유전 실험실: http://localhost:8765/lab.html (부모 12좌위 편집 · 이론 확률/실험 비교 · seed 설정 파일 · 100/1,000/10,000회 교배 통계)
- 월드·UI 자동 검사: http://localhost:8765/smoke.html (실제 게임 HTML·메모리 저장으로 교배·돌봄·검색·관찰·청소·렌더 자원 등 자동 검사. 원래 진행은 변경하지 않음)
- 회귀 테스트: Node.js 24에서 `npm test` (추가 패키지 설치 불필요). GitHub Actions에서도 실행합니다.
- 브라우저 회귀 테스트: `npm ci` → `npx playwright install chromium` → `npm run test:browser`. 데스크톱·390px 화면에서 실제 UI를 검사하고 `test-results/`에 보고서·스크린샷을 남깁니다. CI에서도 실행하도록 구성했으며, 테스트의 Three.js는 고정된 로컬 패키지를 사용합니다. 게임 실행에는 이 개발용 패키지가 필요하지 않습니다.
- 우리집의 `진행 백업` / `백업 불러오기`로 진행을 JSON 파일로 보관·복원할 수 있습니다. 실험실 설정 파일과 게임 저장 파일은 별개입니다.
- 손상된 자동 저장은 게임 시작 전에 복구 화면에서 원본 다운로드·백업 복구·새 게임을 선택합니다. 선택 전에는 원본을 덮어쓰지 않습니다.
- 상단 `🔇` 버튼을 누르면 작은 합성 배경음악과 돌봄·교배·수입 효과음을 켤 수 있습니다. 처음에는 소리가 꺼져 있고 탭을 숨기면 일시 정지합니다.
- 우리집 `소리 설정`에서 배경음악과 효과음을 따로 조절합니다. 0%면 해당 소리만 끄며 음량은 이 브라우저에 저장됩니다. 재접속 시에는 소리를 직접 켜야 합니다.
- 각 우리에는 두 자리의 지붕·방석 쉼터가 있습니다. 소심한 고양이가 빈 자리를 골라 쉬며 다른 고양이와 자리를 중복 예약하지 않습니다. 애교·장난 행동은 이동하는 친구를 추적하고 도착하면 서로 마주 보고 인사합니다. 돌봄·낮잠·쉼터 이용 중인 친구는 방해하지 않습니다.
- 교배 연출은 버튼 또는 Escape로 건너뛸 수 있습니다. 연출 프레임 오류가 나도 교배 결과·저장된 새끼를 보존하고 결과 화면으로 복귀합니다.
- 터치 기기 또는 좁은 화면에서는 왼쪽 아래 조이스틱으로 이동할 수 있습니다. 패널·대화창을 열거나 터치가 취소되면 이동을 멈춥니다.
- 우리집에서 `월드에서 보기`를 누르면 선택한 고양이를 가까이 관찰합니다. 화면 드래그로 카메라를 회전하고 `집사에게 돌아가기` 또는 이동 입력으로 기본 시점에 복귀합니다.
- 화장실에는 고양이별로 4시간마다 청소 오브젝트가 쌓입니다(최대 3개). 월드의 오브젝트/청소 간판을 클릭하면 해당 고양이의 청소 상태를 회복합니다. 렌더는 최대 12개, 간판과 우리집에는 전체 개수를 표시합니다. 유전·성격·수입 확률에는 영향이 없습니다.
- 조작: WASD/방향키 또는 클릭으로 이동. 내 우리의 고양이를 클릭하면 돌보기 창, 동물샵·교배집·이웃 NPC에 다가가면 해당 창이 열립니다.
- 키보드: Tab으로 메뉴·고양이 카드·부모 슬롯을 이동하고 Enter/Space로 선택합니다. 대화창의 Tab 초점은 안에서 순환하고 Escape로 대화창부터 닫습니다. 패널을 다시 그려도 선택·검색 입력 초점과 커서를 유지합니다.
- 판매·새 게임·백업 복원은 페이지 안 확인 창에서 실행/취소하며, 취소하면 진행은 바뀌지 않습니다. 도감 검색은 한글 조합이 끝난 후 자동 갱신합니다.
- 우상단 `+1시간` `+1일` 은 개발용 시간 건너뛰기(성격 형성·쿨다운 확인용)

설명 범주 3개: ① 멘델/복대립 ② 성염색체 연관(Barr body는 하위 메커니즘) ③ 다유전자
